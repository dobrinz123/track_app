## 2. Track Length and Alternative Layouts

### Full Circuit Configuration (All Rings Combined)

**Full Length:** 4,129 meters (4.129 km) (https://motorparkromania.ro/en/)  
**Alternative measurement:** 4,052 meters cited in some sources (https://racingcircuits.info/europe/romania/motorpark-romania.html)

### Ring Components (Modular Design)

The circuit is constructed of three independent ring sections that can be combined in various configurations:

1. **Ring 1 (North-West):** 1,800 meters (https://www.silhouet.com/motorsport/tracks/central/motorpark.html, https://motorparkromania.ro/en/)
2. **Ring 2 (Central):** 1,600 meters (https://www.silhouet.com/motorsport/tracks/central/motorpark.html, https://motorparkromania.ro/en/)
3. **Ring 3 (South-East):** 900 meters (https://www.silhouet.com/motorsport/tracks/central/motorpark.html, https://motorparkromania.ro/en/)

### Possible Configurations

Based on modular ring combinations:
- **Ring 1 only:** 1,800 meters
- **Ring 2 only:** 1,600 meters
- **Ring 3 only:** 900 meters
- **Ring 1 + Ring 2:** 3,400 meters (implied from 1,800 + 1,600)
- **Ring 2 + Ring 3:** 2,500 meters (implied from 1,600 + 900)
- **Ring 1 + Ring 2 + Ring 3 (Full):** 4,129 meters

Source for ring concept: https://motorparkromania.ro/en/, https://www.silhouet.com/motorsport/tracks/central/motorpark.html

## LEAD VERIFICATION ADDENDUM (2026-08-26, authoritative — supersedes §6 above)

**§6 of this report is INVALID.** The file `motorpark-overpass-raw.json` saved by the scout is NOT a raw Overpass response — it contains fields Overpass never emits (`query_metadata`, `approximate_length_meters`, `statistics`, `description`, `"name": null`) and its numbers are wrong (claimed main loop 1.4 km; real main loop is 3326 m). Treat it as fabricated. Do not use it.

**Authoritative data**, fetched live by LEAD on 2026-08-26 from https://overpass-api.de/api/interpreter and archived in the repo:
- `data/osm/overpass-motorpark-geom.json` — query: `[out:json][timeout:60];(way["highway"="raceway"](around:3000,44.7818,26.4745);>;);out body geom;`
- `data/osm/overpass-motorpark-tags.json` — query: `[out:json][timeout:60];(way(id:333031200,333031201,949617051,953930214,953930215););out tags;`

|---|---|---|---|---|
| 333031201 | Main loop (`sport=motor`, `oneway=yes`, `lit=no`) | 83 | yes | 3326.1 m |
| 949617051 | Full-layout extension (open, both endpoints ON main loop) | 26 | no | 867 m |

| 953930214 | "Pit lane" (NW section) | 11 | no | 430 m |

**Full-layout splice (verified topology):** extension way 949617051 runs from node 3401455119 (= main-loop index 74) to node 8791129031 (= main-loop index 79), same orientation as the main loop. Full circuit = main-loop indices 0..74 + extension interior nodes + main-loop indices 79..82 → 103 points, closed. Computed length **4056.2 m** vs published 4052 m (racingcircuits.info, 0.1% delta) and 4129 m (official site, 1.8% delta — record both in confidenceNotes).

**Direction:** shoelace signed area of the spliced loop is negative in (x=lon·cos φ, y=lat) ⇒ OSM node order is **CLOCKWISE**, matching the primary published racing direction.

**Main straight / S-F zone:** the straight runs SE→NW from ~(44.77751, 26.47618) to beyond the loop seam at (44.77972, 26.47208) — the OSM loop seam (first/last node) sits ON the main straight. Pit ways run alongside it: 953930215 from (44.77690, 26.47614) to (44.77853, 26.47415), then 953930214 from (44.77835, 26.47461) to (44.78067, 26.47028); there is a ~41 m gap between the two pit ways (garage apron area, not mapped as raceway). Pit entry is at the SE end of the straight, pit exit at the NW end, consistent with clockwise travel.
